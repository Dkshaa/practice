# Git Practice Checklist

Use this checklist for each practice session:

- [ ] Pull the latest changes before starting.
- [ ] Create a clearly named branch.
- [ ] Make one focused change.
- [ ] Review `git diff` before staging.
- [ ] Stage only the files that belong to the change.
- [ ] Review `git diff --cached` before committing.
- [ ] Write a concise commit message.
- [ ] Push the branch to GitHub.
- [ ] Open and review a pull request.
- [ ] Confirm checks pass before merging.
- [ ] Verify the change on the default branch after merging.

## Reflection

After merging, note one thing learned and one thing to improve next time.
